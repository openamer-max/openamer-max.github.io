Weiter oben in der Leiter: Mega (100–500B) · Giga (500B–1T) · Tera (1–10T). Jede Stufe erscheint erst, wenn sie trainiert und gemessen ist — nicht vorher. Größe ist kein Selbstzweck: Ultra (32B) erreicht 41 von 45 Punkten, Desktop (14,7B) 44. Pro liegt mit 43 einen Punkt unter Desktop. Wir schreiben die schlechteren Zahlen hin, statt sie wegzulassen.

Offene Schnittstelle

138 Sprachen als kostenlose API — ohne Schlüssel, ohne Tageslimit

Dieselbe Übersetzung, die diese Seite in 138 Sprachen trägt, steht jedem offen. Ein Aufruf, ein JSON, fertig. Kein Konto, kein Token, keine Abrechnung — das Modell läuft auf HuggingFace, nicht auf einem Werbeserver. 

curl -X POST https://openamer-max-openamer-translate.hf.space/translate \
  -H "Content-Type: application/json" \
  -d '{"text":"Sechs Modelle, lokal.","target":"rw","source":"de"}'
