Installation

OpenAmer in fünf Schritten installieren — Windows, macOS und Linux. Dauer: etwa 5 bis 15 Minuten.

Voraussetzungen

  • Windows 10/11 (64-Bit), macOS 13+ oder eine aktuelle Linux-Distribution
  • Internetverbindung (für Download und Abhängigkeiten)
  • ca. 2 GB freier Speicherplatz
  • Für lokale Sprachmodelle: 16 GB RAM empfohlen, GPU optional

Die fünf Schritte

1Terminal öffnen

Windows: Startmenü → «PowerShell» eintippen → Rechtsklick → «Als Administrator ausführen».

macOS / Linux: Terminal öffnen (bei macOS: Programme → Dienstprogramme → Terminal).

2Installationsbefehl ausführen

Windows (PowerShell):

iex (irm https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.ps1)

macOS / Linux:

curl -fsSL https://raw.githubusercontent.com/openamer/openamer/main/scripts/install.sh | bash

Das Skript prüft Python und uv, lädt das Projekt, installiert alle Abhängigkeiten und baut die Oberfläche.

3Installation abwarten

Je nach Rechner und Internetverbindung dauert dieser Teil 5 bis 15 Minuten. Im Terminal erscheinen Meldungen wie:

[OK] Managed uv found
[OK] Main package installed (hash-verified via uv.lock)
[OK] ALL dependencies installed
[OK] Interface built

Bitte das Fenster in dieser Zeit nicht schliessen.

4Setup-Wizard durchlaufen

Nach der Installation startet automatisch der Einrichtungsassistent. Er fragt:

  • Modell / Anbieter: lokal (kein Schlüssel nötig) oder Cloud (API-Schlüssel erforderlich)
  • Terminal-Backend: lokal empfohlen
  • Messaging-Plattform: Telegram, Discord usw. — optional, kann übersprungen werden
  • API-Schlüssel: nur bei Cloud-Modellen

Die vorgeschlagenen Standardwerte sind für den Anfang geeignet.

5Starten

openamer

Beim ersten Start erscheint die Oberfläche mit der Liste der verfügbaren Werkzeuge — über 120 an der Zahl.

Speicherorte

WasWo (Windows)
Einstellungen%LOCALAPPDATA%\openamer\config.yaml
API-Schlüssel%LOCALAPPDATA%\openamer\
Protokolle%LOCALAPPDATA%\openamer\logs
Skills%LOCALAPPDATA%\openamer\skills

Auf macOS und Linux liegen dieselben Dateien unter ~/AppData/Local/openamer bzw. ~/.local/share/openamer.

Nützliche Befehle

BefehlWirkung
openamerAssistent starten
openamer setupSetup-Wizard erneut ausführen
openamer setup modelModell oder Anbieter ändern
openamer setup terminalTerminal-Backend ändern
openamer toolsVerfügbare Werkzeuge anzeigen
openamer --helpAlle Befehle anzeigen

Deinstallation

Windows (PowerShell):

Remove-Item -Recurse -Force "$env:LOCALAPPDATA\openamer"

macOS / Linux:

rm -rf ~/.local/share/openamer ~/AppData/Local/openamer

Wenn etwas nicht klappt

  • «python nicht gefunden»: Python 3.11 oder neuer installieren, danach das Terminal neu öffnen.
  • Berechtigungsfehler: Terminal bzw. PowerShell als Administrator starten.
  • Download blockiert: Firewall oder Virenscanner prüfen; die Skripte kommen von raw.githubusercontent.com.
  • Build bricht ab: Speicherplatz prüfen (mindestens 2 GB) und den Befehl erneut ausführen — der Installer setzt an der letzten Stelle fort.
Hinweis: OpenAmer läuft vollständig auf deinem Gerät. Es werden keine Gespräche, Dateien oder Konfigurationen an Dritte übertragen — ausser du bindest bewusst einen Cloud-Anbieter an.
