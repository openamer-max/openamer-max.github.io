OpenAmer-Max-Watch · 0,6B Parameter · ohne Anmeldung · läuft auf einem kostenlosen Server mit zwei Kernen.

Frag mich etwas — zum Beispiel, ob OpenAmer etwas kostet oder wo deine Daten bleiben. Ich antworte kurz und sage auch, wenn ich etwas nicht weiß.

Zur Geschwindigkeit, ehrlich: Der Server hat zwei Kerne und keine Grafikkarte. Nach einer Ruhephase lädt das Modell etwa 20 Sekunden, danach antwortet es mit rund 25 Token pro Sekunde — eine kurze Antwort in ein bis zwei Sekunden.

Diese Demo rechnet mit Q4 (378 MB, 44 von 45 Punkten auf dem eingefrorenen Prüfstand). Die ausgelieferte Datei ist Q8 (639 MB, 45 von 45) — sie liegt auf HuggingFace. Für Tempo ohne Wartezeit: ollama run amersacirovic/openamer-max-watch
