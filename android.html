OpenAmer auf Android

Nicht ferngesteuert und keine Hülle um eine Webseite: derselbe Agent, der unter Windows und Linux läuft — auf dem Telefon, mit Werkzeugen, Skills, Erinnerungen und Zeitplänen.

Gemessen, nicht behauptet

Im Android-Emulator (Android 14) ausgeführt, nicht abgeschrieben:

$ proot-distro login debian -- /root/venv/bin/openamer --version OpenAmer Agent v2026.11.16 (2026.11.16) · upstream 8be94c32 Install directory: /root/openamer Install method: git Python: 3.13.5 OpenAI SDK: 2.24.0

Warum ein Debian-Userspace

Zwei Grenzen von Termux sind gemessen, nicht vermutet:

  • libc: Termux läuft auf Androids bionic. manylinux-Räder verlangen glibc — cryptography ließ sich dort nicht bauen.
  • Python-Version: Termux liefert 3.14, der Agent verlangt <3.14.

Debian in proot bringt glibc und Python 3.13. Dort greifen die fertigen Räder, und der Agent startet. Kein Root nötig.

Die fünf Schritte

1Termux installieren

Aus F-Droid — nicht aus dem Play Store, dort ist die Fassung veraltet.

2Termux Befehle erlauben

Einmalig in Termux eintippen — sonst darf der Launcher nichts starten:

echo "allow-external-apps=true" >> ~/.termux/termux.properties

3Launcher installieren

Die APK unten herunterladen und öffnen. Android fragt beim ersten Start nach der Berechtigung „Befehle in Termux ausführen" — erlauben.

4Agent installieren

Im Launcher auf Agent installieren tippen. Termux lädt Debian und den Agenten — einige Minuten, einmalig.

5Starten

Auf OpenAmer starten tippen. Es öffnet sich dieselbe Textoberfläche wie unter Windows und Linux.
